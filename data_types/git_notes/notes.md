## command for adding user

`git config -- globel user.name yourname`
 
## command for adding user's email

`git config --global user.email youremail`

## command for list config details

`git config --list`

## command for initializing git

`git init`

## comand for adding all changes to staging area
`git add -A`

## command for adding staged files to local repository

`git commit -m "commit messege"`

## command for working tree clean or list all untraked  files

`git status`
